# Линия жизни

Браузерный прототип для проверки игровых циклов. Графика, тексты и условные шкалы пока используются для настройки логики.

## Последняя версия

Включены все опубликованные правки из сборки `8b934b3a3352fb5fca0fc0cf6e10d17cfd23eee4` от 27 октября 2026 года:

- Рождение с вероятностями по данным ООН за 2023 год для 237 стран и территорий.
- Сцены первых лет, семейные условия и постепенно проявляющиеся интересы.
- Месячное течение времени, пауза, скорости 1×, 3× и 6×.
- Компактная пиксельная сцена рядом с решениями, без изометрии.
- Лента обычных событий, семейных и рабочих изменений, вымышленных местных новостей и отложенных последствий.
- Занятия и профессии персонажа и близких.
- Необязательные цели, история, финал и сохранение в браузере.
- Редкий тестовый сюжет об огнях в небе с разными продолжениями.

Лишний блок про «маленькую жизнь» удалён. Первая школьная сцена — «После уроков». Игровые файлы перенесены без изменений; добавлены только проверка файлов, конфигурация публикации и инструкции.

## Локальный запуск

Сборка и установка библиотек не требуются:

```sh
python3 -m http.server 8080 --directory dist
```

Откройте `http://localhost:8080`. Для проверок нужен Node.js 22 или новее:

```sh
npm run check
npm test
```

## GitHub Pages

1. Создать репозиторий с основной веткой `main` и загрузить проект.
2. В Settings → Pages выбрать источник GitHub Actions.
3. Запустить workflow `Test and publish prototype` либо отправить изменение в `main`.

Проверки проходят до публикации. Публикуется только `dist/`. Pull request проверяется, но не публикует игру. Финальный адрес нужно брать из успешного запуска GitHub Pages; здесь он ещё не назначен.

На GitHub Free для Pages нужен публичный репозиторий. Сайт статический, без пользовательских аккаунтов и ключей доступа. Публикация использует стандартный `GITHUB_TOKEN`, отдельные секреты не нужны.

## Файлы проекта

- `dist/engine.js` — базовые решения, детство, семья.
- `dist/timeline.js` — время, события, профессии и последствия.
- `dist/live-scene.js` — компактные временные пиксельные сцены.
- `dist/app.js` — интерфейс и сохранение.
- `dist/birth-data.js`, `dist/births-2023.csv` — готовые веса рождения.
- `tests/` — проверки симуляции и статистического выбора страны.
- `data/` — отфильтрованные исходные строки и происхождение данных.
- `tools/` — проверка файлов и подготовка статистики.

Пути относительные и подходят для подпапки проекта GitHub Pages.

## Ограничения теста

Профессии, доходы, отношения, характер, события и эффекты решений пока не откалиброваны по статистике стран. Новости вымышлены. 76 лет — конец сценария, не прогноз смерти. Полноценной самостоятельной симуляции всех близких пока нет.

Источник рождения: United Nations, DESA, Population Division, World Population Prospects 2024 с обновлением по Того, CC BY 3.0 IGO. Подробнее — `data/README.md`. Собственная игра не получает автоматически эту лицензию.

Сохранения живут в localStorage браузера и конкретного адреса сайта. Между старым адресом и GitHub Pages они автоматически не переходят. Экспорт текстовой истории не является экспортом игрового сохранения. Исходники не содержат сохранений пользователя.
